Food Finder Guide

Built with zero external API keys, zero tracking, and offline browser storage.

  • / — Focus the custom filter input immediately.
  • Esc — Close recipe view or active modal dialogs.
  • ? — Open this help guide anytime.
  • Serving Scaler: Multiply or divide ingredient amounts dynamically (0.5x to 3x).
  • Cook Mode: Enlarges recipe text and requests screen wake-lock while your hands are busy.
  • Proxy Switcher: If a food site blocks one public proxy with a 403 error, switch proxies in the top toolbar and retry.
